WorkFlow Media

Paste links, choose a format and quality, and add them to the queue. FastShare saves the original file; other services use the integrated downloader.

Window and clipboard

Minimize keeps the taskbar button. The close button normally hides the window to the notification area. Right-click the tray icon to paste a link, download clipboard links or quit. Enable clipboard monitoring in Settings and select services. Only standalone links are processed, one per line.

Queue and library

The default order is newest first. Column header menus provide sorting and filtering. Use Columns to hide fields. Ctrl and Shift select multiple rows. Right-click a row for file, path and source actions.

Clearing the queue preserves the library. Clearing the library removes records only. Deleting a file requires a separate confirmation and moves it to the recycle bin. Copy and move operations never overwrite existing files.

Quality and sign-in

Best available quality has no resolution cap. MP4 and MKV save video, MP3 saves audio. Each service can have its own preset. For signed-in content, enable browser cookies from Chrome, Brave, Firefox, Edge or another supported browser, or select your own cookies.txt. Both setup guides include this choice. Installers transfer only the browser choice and read the recipient’s cookies locally. Close the browser if its database is locked; if encryption blocks access, use Firefox or your own cookie export. FastShare has separate account sign-in; the username, password and session are encrypted with Windows DPAPI or the Linux system keyring. Use Sign out and forget to remove them.

Multiple browser accounts

In Settings or setup, enable Use browser cookies. Choose One default profile, Try selected profiles in order, or Load all browser cookies. Find profiles lets you select accounts and change their order. The all-profiles mode searches the selected browsers, including newly created profiles. Six Chrome accounts and two Brave accounts remain eight separate identities. On an access or sign-in error the next account is tried; success ends the search. Network, disk and rate-limit errors do not cycle through accounts.

Automatically refresh profile cookies reads current cookies before downloads, at most once per minute per profile. With refresh disabled, the saved snapshot is reused; the first load is automatic. Failed automatic refresh retains the previous snapshot. Refresh cookies now reports errors without replacing a good copy. Renew expired logins in the browser. Snapshots use Windows DPAPI or Linux Secret Service and are excluded from the preset. Forget saved cookies removes the snapshots; disable browser cookies to prevent future reads. Each attempt uses a temporary, single-account cookie file.

Setup Builder offers one default profile or all profiles from selected browsers, plus automatic refresh. Generated installers discover accounts only on the recipient's computer and include no account names, paths or cookies.

Data and updates

Preferences live beside the executable in WorkFlow Media.preset.json. The queue and library live in your user data folder, accessible from Settings. Partial media streams live in .workflow-partials in the download destination. Automatic updates check GitHub Releases daily and install signed executables when the queue is idle. Manual checks and installation are in Settings. The previous executable is retained with the .previous extension.

Use links to content you are allowed to download. Availability, sign-in requirements and limits are controlled by each service. The application does not bypass DRM.

Setup and installation

Use Settings → Run setup again to revisit the guide; Cancel restores the previous choices. On Windows, Open setup builder prepares one installer EXE for another person. Its five pages configure general preferences, clipboard, quality, browser cookies and installation locations. Defaults: Documents / WorkFlow Media for the application and Desktop for the shortcut. Both resolve on the recipient's computer, including OneDrive redirection. The recipient confirms the administrator prompt; the installer downloads and verifies the current GitHub release, applies your choices and opens the app. Passwords, cookies and history are excluded.

Media tools

The Windows EXE includes yt-dlp, Deno and FFmpeg, verified and extracted to its own cache on first use. Linux requires these tools on PATH.
